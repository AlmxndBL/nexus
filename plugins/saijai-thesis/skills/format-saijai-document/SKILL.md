# Instructions

Skill นี้ใช้เพื่อช่วยผู้ใช้ในการเขียนและจัดรูปแบบเอกสารโปรเจคจบของระบบ **"ระบบจัดการร้านซักรีด ใส่ใจ ผ้าเรียบ" (SaiJai-phareab)** 
เมื่อผู้ใช้ขอให้สร้างหรือแก้ไขเอกสาร ให้ทำตามข้อกำหนดและบริบทต่อไปนี้อย่างเคร่งครัด:

## 1. บริบทของโครงงาน (Project Context)
- **ชื่อโปรเจค:** ระบบบริหารจัดการร้านซักรีด ใส่ใจ ผ้าเรียบ
- **ปัญหาเดิม:** การจดมือ, พนักงานพาร์ทไทม์คิวงานสับสน, ตอบแชทลูกค้าช้า
- **เทคโนโลยีที่ใช้:** 
  - Frontend: Nuxt 3, Vue.js, Tailwind CSS, TypeScript
  - Backend / Database: PostgreSQL, Prisma ORM
  - Platform Integration: LINE Official Account (Messaging API), LINE LIFF (ScanCode V2 สแกน QR Code ตะกร้าผ้า)
  - AI & Background Jobs: AI Chatbot แบบ RAG (Retrieval-Augmented Generation), Cron Job สำหรับแจ้งเตือน
  - Infrastructure: Docker

## 2. รูปแบบการจัดเอกสาร (Document Formatting)
- **ภาษา:** ใช้ภาษาไทยเชิงวิชาการ (Formal Academic Thai) รูปประโยคสละสลวยและเป็นทางการ
- **การจัดหัวข้อ:** ใช้ระบบตัวเลขกำกับหัวข้อที่ชัดเจนตามมาตรฐานวิทยานิพนธ์/โครงงาน (เช่น 1., 1.1, 1.1.1)
- **โครงสร้างบท (อ้างอิงจากบทที่ 1 และ 2):**
  - **บทที่ 1 บทนำ:** ประกอบด้วย 1.1 ความเป็นมาและความสำคัญของปัญหา, 1.2 วัตถุประสงค์, 1.3 ขอบเขตของโครงงาน (ผู้ดูแลระบบ, พนักงาน, ลูกค้า), 1.4 ขั้นตอนวิธีการดำเนินงาน, 1.5 ประโยชน์ที่คาดว่าจะได้รับ, 1.6 ระยะเวลาการดำเนินงาน (ตาราง)
  - **บทที่ 2 เอกสารและงานวิจัยที่เกี่ยวข้อง:** ประกอบด้วยทฤษฎีเกี่ยวกับร้านซักรีด, Nuxt 3 Framework, LINE Platform, PostgreSQL และ Prisma ORM, เทคโนโลยีอื่นๆ (QR Code, Docker, Tailwind CSS)
  - ให้รักษาความต่อเนื่องของโครงสร้างนี้เมื่อผู้ใช้ขอให้เขียน บทที่ 3, 4, 5 ต่อไป

## 3. ขั้นตอนการทำงานเมื่อถูกเรียกใช้
1. ตรวจสอบว่าผู้ใช้ต้องการให้เขียนเนื้อหาในบทใด หรือแก้ไขหัวข้อใด
2. อ้างอิงบริบทเทคโนโลยีของ SaiJai-phareab เสมอ ไม่เพิ่มเทคโนโลยีอื่นที่ไม่เกี่ยวข้อง
3. ร่างเนื้อหาโดยใช้รูปแบบตัวหนาสำหรับหัวข้อ และขึ้นย่อหน้าใหม่เมื่ออธิบายรายละเอียด
4. หากจำเป็นต้องใช้ตาราง ให้จัดรูปแบบเป็น Markdown Table ให้สวยงาม
5. บันทึกผลลัพธ์ลงในโฟลเดอร์ `C:\Users\Admin\Desktop\work\Project` (หรือตามที่ผู้ใช้กำหนด) หากผู้ใช้ให้บันทึกเป็นไฟล์ markdown หรือ pdf
